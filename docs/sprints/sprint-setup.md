# Sprint Setup Guide

## 1. Sprint Planning
- **Duration**: 2 weeks (standard)
- **Ceremonies**:
  - Sprint Planning (Day 1)
  - Daily Standup (15 mins)
  - Sprint Review (Last day)
  - Sprint Retrospective (Last day)

## 2. Backlog Management
- Use GitHub Projects or Jira
- Prioritize using MoSCoW method
- Estimate story points (Fibonacci: 1, 2, 3, 5, 8, 13)

## 3. Definition of Ready (DoR)
- [ ] User story clearly defined
- [ ] Acceptance criteria documented
- [ ] Dependencies identified
- [ ] Estimated by team
- [ ] UI/UX designs available (if applicable)

## 4. Definition of Done (DoD)
- [ ] Code implemented and reviewed
- [ ] Unit tests written and passing
- [ ] Integration tests passing
- [ ] Documentation updated
- [ ] Deployed to staging
- [ ] Product Owner approval

## 5. Sprint Goals Template
```markdown
### Sprint {N} - {Date Range}
**Goal**: {Primary objective}

**Committed Stories**:
- [ ] STORY-001: {Title} ({Points})
- [ ] STORY-002: {Title} ({Points})

**Capacity**: {Total points}
**Commitment**: {Total points}
```

## 6. Tools Setup
- GitHub Projects for task tracking
- ZenHub or GitHub Milestones for sprint management
- Slack/Teams for daily communication
- Confluence/Notion for documentation
